## Memory

- At the start, read `MEMORY.md` to learn the project state and the decisions taken.
- When you finish a task, update it: current state, important decisions (with the why) and findings with mistakes to avoid.
- Keep it short (~100 lines max): summarize or remove what no longer helps.
- If something becomes a permanent rule, propose moving it to `AGENTS.md` instead of keeping it in memory.
- Never store sensitive data (keys, tokens, personal data).
